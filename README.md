# Домашнее задание к работе 6

## Условие задачи

Написать программу, которая после введенного с клавиатуры числа
(в диапазоне от 1 до 99), обозначающего денежную единицу, дописывает
слово "копейка" в правильной форме. Например, 5 копеек, 41 копейка и т. д.

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **НАЧАЛО**
2. Вводим: n
3. Проверяем условие: n % 10 = 1 и n != 11?
   - Да: Выводим: n копейка
   - Нет: переходим к шагу 4
4. Проверяем условие: n % 10 = 2, 3, 4 и n != 12, 13, 14?
   - Да: Выводим: n копейки
   - Нет: переходим к шагу 5
5. Выводим: n копеек
6. **КОНЕЦ**
